Portfolio Manager for Jira

A powerful Jira Forge application designed to give project managers and team leads a comprehensive, high-level view of their project portfolios. Seamlessly integrated into your Jira environment, it provides interactive dashboards for project health, dependency tracking, and epic roadmaps.

✓ Available on Jira Marketplace

Key Features

  • Projects Dashboard – View all projects at a glance with real-time statistics on total, in-progress, done, and blocked issues.
  • Dependency Visualization – Track issue links (Epics & Stories) across projects with built-in circular dependency detection.
  • Roadmap Timeline – Visualize Epic timelines with start and due dates, including automatic detection of overlapping schedules.
  • Advanced Filtering & Sorting – Filter by project lead, status, date ranges, and search by project name or key. Sort data by any column.
  • Real-Time Stats – Automatically refreshes project statistics in the background to ensure you always have the latest data.
  • Accessibility First – Full keyboard navigation, screen reader announcements, and Right-to-Left (RTL) language support.
Perfect For:

PMO Teams • Program Managers • Agile Release Trains • Cross-Project Dependency Tracking • Executive Reporting

How It Works

  1. Install "Portfolio Manager for Jira" from the Jira Marketplace as a Forge app.
  2. Grant the necessary permissions to access your Jira projects and issues.
  3. Open the app from your Jira application menu.
  4. Navigate between Projects, Dependencies, and Roadmap tabs to analyze your portfolio.
  5. Use advanced filters to drill down into specific project leads, statuses, or date ranges.

❓ Frequently Asked Questions

Q: Does this app work with Jira Server or Data Center?

A: Currently, Portfolio Manager is built as a Jira Forge app, which means it is exclusively available for Jira Cloud.

Q: What permissions does the app require?

A: The app requires read access to your Jira projects, issues, and issue links. It does not modify any of your Jira data. All processing happens securely within Atlassian's Forge infrastructure.

Q: How does the "Circular Dependency" warning work?

A: In the Dependencies tab, the app analyzes the issue links between Epics and Stories. If it detects a loop (e.g., Issue A blocks Issue B, which blocks Issue A), it will display a warning banner to help you resolve the logical conflict.

Q: Can I filter projects by specific dates?

A: Yes! The Projects and Roadmap tabs include date range filters. You can filter to see only projects or epics that overlap with a specific start and end date.

Q: Why are some project stats showing "..." or taking time to load?

A: The app fetches real-time statistics for each project. If you have a large number of projects, it may take a few moments to query Jira for all the issue counts. The data refreshes automatically in the background.

🔒 Permissions & Security: As a Jira Forge app, Portfolio Manager for Jira runs on Atlassian's secure infrastructure. It only requests read access to project metadata, issue details, and issue links to generate your portfolio views. No data is stored outside of Atlassian's environment.

  • No Coding Required – Works directly in Google Sheets™ with an intuitive interface
Perfect For:

Project planning • Agile workflows • Construction timelines • Academic research • Event management • Workflow tracking • Team coordination

How It Works

  1. Install the add-on from Google Workspace Marketplace
  2. Configure your task data in Google Sheets
  3. Map your columns to task properties

Q: Do I need coding skills to use this add-on?
